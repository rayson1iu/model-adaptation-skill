# 验证与测量

本参考用于实测阶段。指定 `level` 时先按 [分级执行与交付](levels.md) 确定必需项：P0 包含训练与端到端性能剖析，P1 的微调按条件决定；P2 不进入本参考中的执行流程。

## 固定实验配置

使用 [实验配置模板](../assets/experiment-profile.md) 或项目等价文件，记录实际运行配置及来源；正式实验前固定输入、比较对象、必选指标、门槛及统计方法。既有方法优先，不把示例参数当作所有模型的默认验收标准。无已定义门槛时可报告诊断测量，但不能声称验收通过。

每次新实验使用独立 run-id。相同实验续跑时先核对已有进程、检查点和完成阶段，记录续跑段与变更；不将另一轮实验追加成原运行的连续结果。实际加载版本优先于事后代码快照。

## 分层执行

按所需范围依次检查：硬件识别 → 框架导入与设备可用 → GPU 基础算子 → 模型导入 → 权重及组件加载 → 推理 → 必要时训练一步。某阶段失败时保存证据并定位，不把前级通过扩展为后级通过。

- 检查实际设备执行，禁止 GPU 不可用时静默回退 CPU。显式 CPU 参考单独标识。
- 优先真实样例，核对输入处理、输出字段、形状、类型、非预期 NaN/Inf 和后处理。合成输入单独标识。
- 对机器人动作说明维度顺序、单位、坐标系、旋转表示、夹爪语义、绝对/增量控制和归一化统计。裁剪或离散化可能掩盖差异时保留处理前后输出。
- 连续运行次数、稳定性窗口及内存增长容限由任务配置确定；不将短程推理称为长时稳定性验证。

## 数值对齐

明确比较对象是动作、logits、loss、梯度、单步更新还是任务效果。loss 可使用真实标签计算，但 loss 相对误差的参考是另一配置的 loss，不是标签本身。

并列记录 reference/candidate：所有模型组件与权重指纹、物理设备、存储与计算精度、框架和源码、后端、TF32、局部精度、输入、统计、batch、模式、seed、样本数及实际产物。未核对的条件标为未知；同时改变多个因素时说明混杂，不能直接归因某硬件或后端。

- 数值对齐尽量复用同一预处理 tensor、mask 和随机输入文件；端到端检查另从相同原始输入执行。只固定 seed 不保证不同平台生成相同随机噪声。
- 自回归模型可用共同前缀比较 logits，完整生成另外记录首个分歧和停止行为；扩散/flow 模型固定噪声、采样步骤和状态。
- 声明比较阶段、误差计算精度、统计轴、有效 mask、单位、门槛方向及等号规则；近零分母、零向量和空 mask 按冻结的方法处理，不临时修改指标定义。
- 保存逐样本结果、汇总、失败范围和最大误差位置；诊断指标与验收指标分开。样本数和覆盖范围来自任务，不照抄历史模型。
- 阈值失败如实保留。局部精度修正、后端切换或其他绕过创建独立配置并复验；不覆盖原失败结果，不把诊断专用配置冒充正式验收。

## 性能、资源与剖析

测量前声明模型计算与端到端边界，是否包含读取/解码、预处理、传输、采样、后处理。按项目既有口径执行；跨平台无法统一时分别列出，不能直接求比值。

- 指定 batch、有效 batch、输入形状、精度、缓存策略、预热次数、有效迭代数、重复轮次和同步方法。加载、首次编译、冷启动与稳态分开。
- GPU 异步执行须使用覆盖完整路径的设备事件或明确同步的主机单调计时；端到端结束点等待最终输出可用。阶段同步对重叠的影响须说明。
- 保存逐次耗时及失败次数，报告适用的均值、分位数及统计方法。吞吐按实际完成工作量除以同一测量窗口；区分请求、样本、batch、token 与动作块，不把动作块吞吐解释为机器人控制频率。
- 区分 allocated、reserved、设备工具占用与主机 RSS；记录单位、采集工具、设备范围和峰值方法。采样得到的峰值明确称为采样峰值。
- 正式性能运行不启用 profiler；短程 trace 单独采集。缺 GPU 事件时不能把 CPU-only trace 当 GPU kernel 剖析通过；不重复累加嵌套 annotation，不将 kernel 累计时长当墙钟。
- 优化逐项测试，并复验正确性。推荐收益门槛由任务确定；扩大 batch 的吞吐变化不等于同条件时延优化。
- 仅对配置和计量口径可比的成对实测计算比值，并写明公式、方向和架构/运行时差异。环境就绪不产生模型加速比。

## 按需训练、恢复与任务效果

只有任务要求时执行，不因 skill 涵盖该能力自动扩大范围。选择 P0 即包含训练要求，训练规模与完成依据按约定方案确定，不能停在训练一步就宣称完成；选择 P1 不自动要求微调，按分级规则判断。恢复和闭环仍按任务约定执行。

训练记录真实数据划分、统计来源、冻结参数、优化器、调度器、有效 batch 和实际优化器更新数。诊断步骤不能混入正式训练计数；比较多个训练配置时避免测试污染起始权重。

恢复验证按模型所需保存模型组件、处理器、优化器、调度器、RNG 和数据游标/采样状态。实际退出重启并比较恢复后的行为，使用已声明的容差；文件存在或成功加载不代表恢复一致，更不代表位级确定性。

闭环或公开任务评测单独固定环境版本、任务、初始状态、控制/终止条件、试验次数与指标。离线 loss、动作误差不等于闭环成功率。没有任务环境时按是否属于本次范围记录未验证或被阻塞，不虚构任务效果。
