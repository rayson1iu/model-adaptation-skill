# 工作日志

作为工作索引，每个有意义的工作单元完成后追加记录，链接原始证据而非复制大段输出。默认使用 Asia/Shanghai，项目另有约定则沿用并标明。历史记录不改写为新实测。

## 填写时间及时区 — 本次目标

- 记录性质：新实测 / 修改 / 诊断 / 复验 / 历史复核
- 实际操作、命令或入口及变更文件：
- run-id、Profile、环境/版本：
- 结果、关键指标、流程状态与验收状态：
- 日志、报告、ISSUE 及必要图表的相对链接：
- 已同步的文档与状态：
- 未解决项、缺失条件、下一步：
- 后台任务标识、当前阶段、恢复入口（适用时）：

仅解释既有信息且没有新操作、结论或状态变化时无需追加。
