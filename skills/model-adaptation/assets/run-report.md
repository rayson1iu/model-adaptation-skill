# 运行报告：填写模型与 run-id

用一段话说明目标、实际执行范围、主要发现和当前验收结论。明确新实测、诊断或历史复核。

- 报告时间及时区、运行起止时间：
- 目标适配级别（P0/P1/未指定）、实际完成范围与范围裁剪说明：
- Profile、环境/源码/权重指纹与实际命令链接：
- 原始日志、指标、输入清单与其他产物位置：
- 流程状态（运行中/已结束/中断等）：
- 验收状态与适用范围（未验证/通过/失败/被阻塞/不适用）：

没有执行的项不能写成通过；安装、算子、模型、数值和任务效果分别说明。

指定级别时逐项列出必需阶段，说明整体是否完成及依据；P1 写明微调是否需要、决策依据与结果。必需项缺失、失败或被阻塞时不宣称目标级别完成。P2 仅输出技术报告，不使用本实测模板。
